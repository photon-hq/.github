## What Photon does

Photon connects AI agents to iMessage, WhatsApp Business, Telegram and Slack. Create a project at [app.photon.codes](https://app.photon.codes), and your agent sends and receives iMessages on a hosted line, with no Mac to run.

- [spectrum-ts](https://github.com/photon-hq/spectrum-ts): the TypeScript SDK. Write one message handler for iMessage, WhatsApp Business, Telegram and Slack.
- [skills](https://github.com/photon-hq/skills): agent skills that teach coding agents to use Photon's SDKs and CLI.
- [cli](https://github.com/photon-hq/cli): the `photon` command for the Photon dashboard.
- Templates: [Hermes Agent on iMessage](https://github.com/photon-comm/hermes-agent), [the OpenClaw iMessage plugin](https://github.com/photon-comm/openclaw-photon) and [an eve agent on Vercel](https://github.com/photon-comm/eve-agent).

Docs: [photon.codes/docs](https://photon.codes/docs)
